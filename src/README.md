# d77void Immutable Docs

This is the community documentation of **d77void Immutable**: a Void Linux
with runit and without systemd, where the system is a read-only image that is
replaced as a whole on every update, with the previous version always there
to go back to.

These pages explain how the system really works and how to run it and
recover it yourself. Every procedure here is checked against the system's
code and, where it says so, on real installations.

> **Work in progress.** d77void Immutable is heading for a Technology Preview
> on 6 January 2027. It installs, boots and updates itself on real hardware,
> but it is still a test system.

## Where to start

- New to immutable systems? Read [What d77void Immutable is](getting-started/overview.md).
- Want to know what happens when it updates? Read [A/B slots and updates](system/slots-ab.md).
- Not sure an update went through? Follow [Checking an update](system/verify-update.md).
- Looking for a program? See [Where to install applications](applications/choosing-method.md).
